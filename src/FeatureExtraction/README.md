# Feature Extraction

## Incremental Slow Feature Analysis (IncSFA)

- Artigo: Kompella, Luciw e Schmidhuber – “Incremental Slow Feature Analysis: Adaptive and Episodic Learning from High-Dimensional Input Streams”.

Resultado obtido: Os autores demonstraram que o método mantém qualidade de extração semelhante ao PCA tradicional enquanto reduz drasticamente custo computacional e memória, tornando possível o processamento contínuo de fluxos de alta dimensionalidade. É hoje uma das bases de diversos extratores adaptativos posteriores.
